# SIGO-Dental — Sistema Integral de Gestión Odontológica

Proyecto construido a partir del SRS v1.0 (29/10/2026), con el mismo stack y forma de trabajo que catalogo-multinivel:
React + Vite + Tailwind (JavaScript, PWA) en la raíz y Go + Fiber en `sigo-backend/`, PostgreSQL 16 y Redis.

Este primer commit contiene el análisis de requisitos y el plan. El código llega por etapas, cada una en su rama:

- `docs/01-analisis-requisitos.md` — inventario de RF/RNF/RN, ambigüedades, supuestos y preguntas al cliente.
- `docs/04-matriz-permisos.md` — roles y permisos.
- `PLAN_IMPLEMENTACION.md` — etapas 1 a 7 con criterios de aceptación.

Todos los datos del proyecto son ficticios.
